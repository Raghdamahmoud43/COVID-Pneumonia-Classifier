# 🩺 COVID-19 & Pneumonia Classification Model

A deep learning model designed to classify chest X-ray images into three categories:

* 🦠 **COVID-19**
* 🫁 **Pneumonia**
* ✅ **Normal**

## 📌 Project Overview

This project uses deep learning and computer vision techniques to analyze chest X-ray images and classify them into three different classes.

The model was trained and evaluated using a labeled chest X-ray dataset containing images from the three categories.

> **Note:** This project is intended for educational and research purposes and should not be used as a medical diagnostic tool.

## 🎯 Model Performance

The model achieved approximately **97.46% accuracy on the test set**.

### Test Results

| Class     | Precision | Recall | F1-Score |
| --------- | --------: | -----: | -------: |
| COVID-19  |    98.79% | 99.59% |   99.19% |
| Normal    |    95.70% | 98.52% |   97.09% |
| Pneumonia |    98.08% | 94.44% |   96.23% |

**Overall Test Accuracy: 97.46%**
